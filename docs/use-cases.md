# CRAlign — Use Cases

Real-world problems CRAlign helps with.

> CRAlign supports clinicians; it does not replace professional medical judgment, diagnosis, or care.

## Rehabilitation Clinics

MSK intake and assessment are time-consuming. CRAlign streamlines the structured parts so clinician time goes to judgment and care, not paperwork.

## Physical Therapy Practices

A conversational intake plus AI-assisted structuring gives therapists organized, review-ready assessments — with the clinician review workflow keeping a qualified human in control.

## Telehealth Providers

Remote MSK assessment is hard to standardize. CRAlign provides a structured, consistent intake-and-review flow suited to telehealth delivery.

## Multi-Clinician Networks

State-based assignment routes each case to an appropriately licensed clinician — useful for practices and networks operating across regions.

## Ongoing Rehabilitation Programs

With journaling and progress tracking, CRAlign supports the full rehabilitation journey, not just the first appointment.
