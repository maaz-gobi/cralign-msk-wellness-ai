# CRAlign — Features

A detailed look at what CRAlign does. (Marketing documentation — no implementation details.)

> CRAlign supports clinicians; it does not replace professional medical judgment, diagnosis, or care.

## Conversational Patient Intake

- A guided, patient-friendly assessment experience.
- Replaces rigid forms with a conversational flow.
- Designed to collect relevant MSK information thoroughly and comfortably.

## AI-Assisted Analysis

- Helps structure and organize intake information.
- Surfaces relevant details for the reviewing clinician.
- Assists the clinician — it does not make clinical decisions.

## Clinician Review Workflow

The core of CRAlign. Every assessment passes through a structured review step:

- A licensed clinician reviews each assessment before it is finalized.
- The workflow is built into the product, not bolted on.

## State-Based Assignment

- Routes cases to clinicians licensed appropriately for the patient's location.
- Helps practices stay within professional and regulatory boundaries.

## Role-Based Access

- Separate, permissioned experiences for patients and clinicians.
- Each role sees only what is appropriate to it.

## Journaling & Progress Tracking

- Supports the ongoing rehabilitation journey, not just one-time intake.
- Patients and clinicians can track progress over time.

## Compliance-Minded Architecture

- Built privacy-first, with healthcare data handling as a first principle.
